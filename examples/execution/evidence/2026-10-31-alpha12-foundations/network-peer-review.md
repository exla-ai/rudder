No source edits or Cargo commands were performed for this review.

- `NamespaceFd::inspect` validates the actual kernel namespace type, holds the FD and sets CLOEXEC. `verify_owner` checks the NET namespace's owning USER namespace against the held new USER FD. These use the kernel relationship API, not saved inode strings. See [Linux namespace ioctls](https://man7.org/linux/man-pages/man2/ioctl_nsfs.2.html).
- `ChildNetworkBaseline` is neither Send nor Sync. Mutation checks the actual captured PID, actual main thread, one task, UID/GID1500 with no supplementary groups, NNP, exact self maps, new USER and unchanged baseline NET before unshare. Baseline USER/NET FDs are explicitly closed and their old numbers checked EBADF before returning. `child_namespace_fds()` returns only current USER/NET witnesses; integration must still implement its complete init/backend FD allowlist.
- Capability drop clears ambient, then bounding while effective CAP_SETPCAP remains, then effective/permitted/inheritable, then verifies all five sets and NNP. `CapabilityDropProof` cannot be cloned, sent or deserialized; verification rechecks actual PID/TID and fresh kernel state. Unknown capability widths fail closed. The sequence is consistent with the per-thread model in [Linux capabilities](https://man7.org/linux/man-pages/man7/capabilities.7.html); new USER creation can restore capabilities, as described in [user namespaces](https://man7.org/linux/man-pages/man7/user_namespaces.7.html).
- Validated profile, pinned numeric destination and held namespace evidence remain configuration/physical evidence. None constructs live owner/run admission. Full profile digest binds policy, budgets and readiness nonce. Destination checks have no DNS or IPv6 fallback and require an explicit trusted host deny inventory.
- The standalone qualifier is a fresh exact Cargo binary with cleared environment, explicit opt-in, alarm, bounded parent wait and kill/wait on timeout. Destructive operations never run on a libtest thread. Parent namespace/capability checks remain in the parent process.
