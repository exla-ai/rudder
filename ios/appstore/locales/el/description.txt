Το Rudder τρέχει τους coding agents σου (Claude Code και Codex) σε ένα μηχάνημα στο cloud και τους βάζει στην τσέπη σου: διάβασε τις συνομιλίες τους, απάντησε στις ερωτήσεις τους, ενέκρινε αλλαγές, ξεκίνησε νέες εργασίες και κάνε merge τη δουλειά τους από το κινητό σου.

Δες όλα τα projects και τους agents με μια ματιά. Όταν ένας agent έχει μια ερώτηση, χρειάζεται έγκριση ή έχει έτοιμο ένα πλάνο, το Rudder τον ανεβάζει στην κορυφή και εμφανίζει μια ένδειξη, ώστε να απαντήσεις με λίγα αγγίγματα και να τον αφήσεις να συνεχίσει.

Από το κινητό σου μπορείς να:
- Διαβάζεις τη συνομιλία κάθε agent την ώρα που δουλεύει και να του στέλνεις μήνυμα.
- Απαντάς σε ερωτήσεις και να εγκρίνεις ενέργειες και πλάνα.
- Ξεκινάς έναν νέο agent σε οποιοδήποτε project και να διαλέγεις το μοντέλο του.
- Επισυνάπτεις φωτογραφίες, στιγμιότυπα οθόνης και αρχεία σε ένα μήνυμα.
- Μιλάς στο Rudder: ρώτα τι κάνουν οι agents σου ή πες τους τι να κάνουν, με τη φωνή σου.
- Συνδέεις το Claude Code ή το Codex στο μηχάνημά σου στο cloud χωρίς laptop.
- Λαμβάνεις κάθε πρωί μια σύνοψη για το τι έκαναν οι agents σου από χθες.
- Ελέγχεις το μηχάνημά σου στο cloud, τα workspaces του και τη χρήση της συνδρομής σου.

Το Rudder διαθέτει επίσης εφαρμογή για Mac και εργαλείο γραμμής εντολών. Μένουν συγχρονισμένα: ξεκίνα έναν agent στο laptop σου και παρακολούθησέ τον στο κινητό σου.

Το Rudder είναι δωρεάν και ανοιχτού κώδικα. Συνδέεσαι με Apple, Google ή GitHub, και οι agents χρησιμοποιούν τη δική σου συνδρομή Claude ή ChatGPT.
