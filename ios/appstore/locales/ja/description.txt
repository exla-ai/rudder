Rudder は、コーディングエージェント（Claude Code と Codex）をクラウドマシン上で動かし、ポケットの中から扱えるようにします。会話を読む、質問に答える、変更を承認する、新しいタスクを始める、作業をマージする。すべてスマホからできます。

すべてのプロジェクトとエージェントをひと目で確認できます。エージェントから質問が届いたとき、承認が必要なとき、計画ができあがったときは、Rudder がそれを一番上に表示してバッジで知らせます。数回のタップで答えれば、エージェントは作業を続けます。

スマホからできること:
- 作業中のエージェントの会話をその場で読み、メッセージを送る。
- 質問に答え、アクションや計画を承認する。
- 好きなプロジェクトで新しいエージェントを起動し、モデルを選ぶ。
- メッセージに写真、スクリーンショット、ファイルを添付する。
- Rudder に話しかける。エージェントが何をしているか尋ねたり、やってほしいことを伝えたりを、声で。
- ノートパソコンなしで、クラウドマシン上の Claude Code や Codex にサインインする。
- 昨日からエージェントが何をしたかをまとめた、朝のダイジェストを受け取る。
- クラウドマシン、そのワークスペース、プランの使用量を確認する。

Rudder には Mac アプリとコマンドラインツールもあります。これらは同期されているので、ノートパソコンで起動したエージェントをスマホで追いかけられます。

Rudder は無料のオープンソースソフトウェアです。Apple、Google、GitHub のいずれかでサインインし、エージェントはあなた自身の Claude または ChatGPT のプランを使います。
