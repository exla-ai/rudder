Rudder รันเอเจนต์เขียนโค้ดของคุณ (Claude Code และ Codex) บนเครื่องคลาวด์ และให้คุณพกติดกระเป๋าไว้ได้: อ่านบทสนทนา ตอบคำถาม อนุมัติการเปลี่ยนแปลง เริ่มงานใหม่ และ merge งาน ได้จากมือถือ

เห็นทุกโปรเจกต์และทุกเอเจนต์ได้ในพริบตา เมื่อเอเจนต์มีคำถาม ต้องการการอนุมัติ หรือมีแผนพร้อมแล้ว Rudder จะยกขึ้นมาไว้บนสุดและแสดงป้ายแจ้งเตือน คุณจึงตอบได้ในไม่กี่แตะ แล้วให้เอเจนต์ทำงานต่อ

จากมือถือ คุณสามารถ:
- อ่านบทสนทนาของแต่ละเอเจนต์ระหว่างที่กำลังทำงาน และส่งข้อความถึงเอเจนต์
- ตอบคำถาม อนุมัติการดำเนินการ และอนุมัติแผน
- เริ่มเอเจนต์ใหม่ในโปรเจกต์ใดก็ได้ และเลือกโมเดล
- แนบรูปภาพ ภาพหน้าจอ และไฟล์ไปกับข้อความ
- คุยกับ Rudder ด้วยเสียง: ถามว่าเอเจนต์กำลังทำอะไรอยู่ หรือสั่งว่าต้องทำอะไร
- ลงชื่อเข้าใช้ Claude Code หรือ Codex บนเครื่องคลาวด์ได้โดยไม่ต้องใช้แล็ปท็อป
- รับสรุปตอนเช้าว่าเอเจนต์ทำอะไรไปบ้างตั้งแต่เมื่อวาน
- ตรวจสอบเครื่องคลาวด์ เวิร์กสเปซ และปริมาณการใช้งานแพ็กเกจของคุณ

Rudder ยังมีแอป Mac และเครื่องมือ command line ด้วย ทั้งหมดซิงก์กันอยู่เสมอ: เริ่มเอเจนต์บนแล็ปท็อป แล้วติดตามต่อบนมือถือได้

Rudder ใช้ฟรีและเป็นโอเพนซอร์ส คุณลงชื่อเข้าใช้ด้วย Apple, Google หรือ GitHub และเอเจนต์จะใช้แพ็กเกจ Claude หรือ ChatGPT ของคุณเอง
