Rudder 在云端机器上运行你的编程智能体（Claude Code 和 Codex），并把它们装进你的口袋：在手机上就能查看它们的对话、回答它们的问题、批准更改、发起新任务、合并成果。

所有项目和智能体一目了然。当某个智能体提出问题、需要你批准或准备好了计划时，Rudder 会把它置顶并显示角标，你点几下就能回复，让它继续工作。

在手机上，你可以：
- 实时查看每个智能体工作中的对话，并给它发消息。
- 回答问题，批准操作和计划。
- 在任意项目中启动新的智能体，并选择模型。
- 在消息中附上照片、截图和文件。
- 和 Rudder 对话：用语音询问智能体在做什么，或告诉它们该做什么。
- 不用笔记本电脑，就能在云端机器上登录 Claude Code 或 Codex。
- 每天早上收到一份摘要，了解智能体从昨天起做了什么。
- 查看你的云端机器、工作区和套餐用量。

Rudder 还有 Mac 应用和命令行工具。它们保持同步：在笔记本电脑上启动一个智能体，就能在手机上继续跟进。

Rudder 免费且开源。你可以使用 Apple、Google 或 GitHub 登录，智能体使用的是你自己的 Claude 或 ChatGPT 套餐。
