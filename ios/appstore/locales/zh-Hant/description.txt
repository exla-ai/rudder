Rudder 會在雲端主機上執行你的 AI 程式代理（Claude Code 與 Codex），讓你隨身帶著走：用手機就能閱讀對話、回答問題、核准變更、開始新任務，以及合併成果。

所有專案與代理一目瞭然。當代理提出問題、需要你核准或已備妥計畫時，Rudder 會將它置頂並顯示標記，你只要點幾下就能回覆，讓它繼續工作。

用手機，你可以：
- 即時閱讀每個代理工作中的對話，並傳訊息給它。
- 回答問題，核准動作與計畫。
- 在任何專案中啟動新的代理，並選擇模型。
- 在訊息中附加照片、螢幕截圖與檔案。
- 與 Rudder 對話：用語音詢問代理正在做什麼，或告訴它們該做什麼。
- 不需要筆電，就能在雲端主機上登入 Claude Code 或 Codex。
- 每天早上收到摘要，掌握代理從昨天以來做了什麼。
- 查看你的雲端主機、工作區與方案用量。

Rudder 也有 Mac App 和命令列工具。它們會保持同步：在筆電上啟動代理，就能用手機接著追蹤。

Rudder 免費且開放原始碼。你可以使用 Apple、Google 或 GitHub 登入，代理使用的是你自己的 Claude 或 ChatGPT 方案。
